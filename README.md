# Checkout by KPro

A modern ecommerce web app concept focused on:

- AI-native store setup and contextual administration
- Built-in payments (PayPal, cash on pickup, local delivery)
- Real-time carrier pricing simulation (USPS, UPS, FedEx)
- Product/category management and customer account flows
- Interactive 3D product customization preview

## Run locally

```bash
php -S localhost:8000
```

Then open `http://localhost:8000`.
